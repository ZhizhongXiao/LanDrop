UNINSTALL

卸载 LanDrop

正式卸载器将先停止传输服务、关闭 TCP 8000，再删除程序文件和由安装器创建的系统入口。

这是界面草图，不会停止当前 LanDrop 或删除任何文件。

USER DATA

选择要保留的数据

默认保留配置、日志和可信客户机。删除这些数据必须由用户分别明确选择。

CONFIRM

确认卸载

正式流程会清理由安装器创建的快捷方式、通知身份、开机启动项和防火墙规则；不会碰触用户收发的文件。
