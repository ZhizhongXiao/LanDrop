### 检查编号：P1-F01

- 日期：2026-09-15
- 当前网络：手机移动数据热点
- 活动 LAN：WLAN，`10.146.168.152`，Private
- TUN：Meta，`198.18.0.1`，已由 LanDrop 排除
- 防火墙状态：Domain、Private、Public 均开启
- 默认策略：三个 Profile 均为阻止入站、允许出站
- 当前解释器：`C:\App Download\Python 3.12.10\python.exe`
- `Python` Private 规则：允许该解释器从任意地址、任意接口访问任意 TCP 和 UDP 本地端口
- `Python` Public 规则：阻止该解释器从任意地址、任意接口访问任意 TCP 和 UDP 本地端口
- `Python HTTP 8000`：允许 Private Profile 的 TCP 本地端口 `8000`；程序范围和远端地址范围均为 Any
- 结论：固定端口 8000 的规则存在且已启用，但现有 Python Private 通用规则还允许该解释器使用其他入站端口，因此当前防火墙配置并非严格“仅开放 8000”。本次只读检查未修改任何规则。

- 修复：状态原因短语固定为 ASCII `Forbidden`，中文说明仅放入 UTF-8 响应正文。
- 结论：基础下载、不存在文件、写操作拒绝、路径越界防护和停止服务通过；其他扩展文件与重复启停项目尚未验收。
