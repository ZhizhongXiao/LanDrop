## 安全修复

- 启动期不再读取 WLAN SSID 并按 `ProfileName` 猜测网络类别。`Get-NetConnectionProfile` 没有可绑定到接口的 profile 时，该接口保持 `Unknown`，正常 Private 选择流程拒绝启动。
- 新可信浏览器记录写入 `expires_at`，服务端校验凭据时强制最多 365 天有效期。Cookie 的 `max_age` 与服务端期限共用同一常量。
- 旧记录没有 `expires_at` 时按 `created_at + 365 天` 推导；过期、时间无效或无时区记录无法认证，并在验证或可信客户机列表刷新时惰性清理。
- 过期限制缩小被盗 Cookie 的重放窗口，但 HTTP 仍不加密；同一网络中的窃听、实时重放和中间人风险仍存在。
