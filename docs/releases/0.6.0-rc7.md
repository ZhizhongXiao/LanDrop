# LanDrop 0.6.0 RC7

状态：**当前冻结候选，仅用于 Phase 8F 最终发布验收；不是正式 release。**

RC1～RC6 均未进入最终发布验收，现由 RC7 取代。Phase 8F 只能使用下列目录中的冻结产物；验收中不得修改、替换或重新压缩。若发现实际缺陷，先保留现场，再修复并生成新的源码提交、Build ID 和 RC。

RC7 取代 RC6 的原因是修复 Windows 保留设备名的多扩展名漏判：`NUL.tar.gz`、`CON.foo.bar`、`COM1.backup.zip` 以及 `COM¹` / `LPT²` 等现在均按第一个扩展名分隔点前的 root 检测。RC6 二进制不包含此修复。
